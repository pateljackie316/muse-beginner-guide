# Muse 新手指南
> 一份写给刚刚接触 Muse 的朋友的入门指南：先搞懂它是什么，再做好注册后 48 小时内最重要的一件事。

## 一、Muse 是什么？

Muse 是 Meta 推出的个人 AI 智能体（Personal AI Agent）。你可以把它理解为一个拥有自己电脑的 AI 助手：它不只会陪你聊天，还能真正动手帮你跑腿办事。

比如，它可以帮你：

- ✈️ 比较航班、规划行程：告诉它出发地、目的地和时间，让它帮你横向比较不同航班的价格与时间。
- 📝 填写表单：按你的要求填写网页表单、整理报名信息等重复性操作。
- 📄 制作文档：起草、排版、汇总资料，生成可以直接使用的文档。
- ⏰ 安排定时任务：把需要定期做的事情交给它，到点自动提醒或执行。

简单说：你动嘴，它跑腿。刚开始使用时，建议先从一件小事入手（例如整理一份清单、比较一次航班），熟悉它接受指令和反馈结果的方式，再逐步交给它更复杂的任务。

## 二、新手最重要的第一步：48 小时内兑换邀请码

注册 Muse 账号后，**请在 48 小时内兑换邀请码**。这是新手阶段最重要、也最容易错过的一步：兑换入口只在注册后的 48 小时内出现，过期后入口就会消失，无法补领。

兑换路径：

- 📱 手机 App：**设置 > 兑换口令**（Settings > Redeem token）
- 🌐 网页版：**设置 > 通用 > 用量 > 兑换邀请码**（Settings > General > Usage > Redeem invite code）

操作时请注意：打开入口后按页面提示输入邀请码并确认；如果入口已经消失，说明已超过 48 小时窗口。

## 四、给新手的几个小建议

1. 先做一件小事：第一次使用时选一个简单任务，熟悉它的办事节奏。
2. 把指令说具体：时间、地点、预算、格式要求写得越清楚，结果越符合预期。
3. 定期任务交给它：需要重复提醒或执行的事，可以试试定时任务功能。
4. 敏感操作先确认：涉及账号、支付等敏感信息时，先核对页面与需求再授权。
